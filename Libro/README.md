## Material grafico

Los generadores reproducibles estan en `creadores_de_imagenes/`. Sus salidas se guardan en `imagenes/` y se referencian desde los capitulos con rutas relativas.

## Entorno de trabajo

Crear el entorno e instalar dependencias con:

```text
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Ejecutar un generador con `.venv/bin/python Libro/creadores_de_imagenes/generador_NOMBRE.py`.
